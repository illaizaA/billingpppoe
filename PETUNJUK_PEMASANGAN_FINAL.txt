BILLING SALAM - FINAL AUTO MAPPING PPPoE

KONSEP FINAL
- Foto Rumah, Nama KTP, dan NIK dikelola dari Billing.
- Foto rumah opsional saat Tambah Pelanggan.
- Jika belum ada foto, sistem menampilkan placeholder.
- Foto dapat ditambahkan/diganti melalui Edit Pelanggan.
- Username PPPoE, ID teknis PPPoE, Koordinat X/Y, IP, dan Online/Offline tidak diisi Admin Billing.
- Billing yang menyesuaikan ke PPPoE dan menyimpan mapping di database Billing.
- Website PPPoE tidak diubah.
- Billing hanya melakukan GET ke http://202.169.232.239:8078/api/pppoes.

AUTO MAPPING
1. Billing membaca data PPPoE asli.
2. Jika ID Pelanggan Billing sama dengan ID PPPoE, pasangan disimpan otomatis.
3. Jika ID berbeda, Billing mencoba kecocokan pasti Nama Lengkap/Nama KTP dengan lokasi/user PPPoE.
4. Hanya satu kecocokan yang pasti yang akan disimpan.
5. Jika tidak cocok, Billing tidak membuat data dummy. Marker tetap tampil dengan status/koordinat asli PPPoE.

URUTAN PEMASANGAN
1. Backup folder Billing dan database.
2. Masuk phpMyAdmin lalu pilih database Billing yang aktif.
3. Import database_update_billing_pppoe_FINAL.sql.
4. Extract ZIP.
5. Copy/replace file PHP ke folder utama Billing.
6. Copy pppoe_mapping_helper.php ke folder utama Billing.
7. Copy template_import_pelanggan_FINAL.xlsx ke folder utama Billing.
8. Pastikan uploads/foto_rumah dapat ditulis PHP.
9. Logout lalu login ulang.
10. Tekan Ctrl + Shift + R.
11. Tes Tambah Pelanggan tanpa foto.
12. Edit pelanggan lalu upload foto.
13. Buka Monitoring PPPoE dan cek marker merah/hijau, IP, serta koordinat.
14. Tes Import Excel dengan template final.
