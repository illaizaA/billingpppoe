# Billing Multiwilayah / UKOOMED

Satu aplikasi dan satu database untuk BARAN, GUNUNGMANUK, NGASEMAYU, SALAM, TROSARI, dan WADUK.

- Super Admin tetap dapat melihat dan mengelola seluruh alamat.
- Admin wilayah hanya dapat melihat dan mengelola pelanggan sesuai wilayah akun.
- Alamat Admin Wilayah otomatis dikunci ketika menambah atau mengedit pelanggan.
- Alamat baru yang ditambahkan Super Admin otomatis muncul pada filter wilayah Super Admin.
- Perbedaan huruf besar/kecil, spasi, dan salah ketik ringan pada enam wilayah resmi dinormalisasi otomatis.
- User dan data lama tidak dihapus.
- Laporan tetap khusus Super Admin.

Gunakan `database/update_database_6_wilayah.sql` untuk database yang sudah berjalan.
